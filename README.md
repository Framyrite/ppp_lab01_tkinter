## Описание проекта

Программа представляет собой графическое приложение на языке Python
с использованием библиотеки tkinter.

Приложение демонстрирует движение точки по окружности радиусом
200 пикселей. Пользователь может изменять скорость и направление
движения, а также приостанавливать и возобновлять анимацию.

Проект разработан в рамках лабораторной работы №1
по дисциплине «Практикум по программированию».

## Функциональные возможности

### Основной функционал

- Графическое окно размером 600×600 пикселей.
- Отображение окружности радиусом 200 пикселей.
- Анимация движения точки по окружности.
- Движение по часовой стрелке.
- Возможность изменения направления движения.
- Регулировка скорости движения.
- Приостановка и возобновление анимации.
- Отображение текущей скорости и состояния анимации в заголовке окна.

### Дополнительный функционал

- Управление с помощью клавиатуры.
- Ограничение скорости движения допустимыми значениями.
- Автоматические тесты математической модели.
- Разделение программы на независимые модули.

## Управление программой

| Клавиша | Действие |
|---------|----------|
| Пробел | Пауза / продолжение анимации |
| → | Увеличение скорости |
| ← | Уменьшение скорости |
| R | Изменение направления движения |

Для управления необходимо активировать окно программы.

Клавиша R работает при английской раскладке клавиатуры.

```bash
cd ppp_lab01_tkinter
```

### 2. Создание виртуального окружения

Для macOS и Linux:

```bash
python3 -m venv venv
```

Для Windows:

```bash
python -m venv venv
```

### 3. Активация виртуального окружения

macOS / Linux:

```bash
source venv/bin/activate
```

Windows:

```bash
venv\Scripts\activate
```


```bash
python main.py
```

После запуска откроется графическое окно
размером 600×600 пикселей.

В центре окна будет отображаться окружность,
по которой непрерывно движется красная точка.

## Математическая модель

Движение точки реализовано с использованием
параметрического уравнения окружности:

```text
x = center_x + R * cos(angle)
y = center_y + R * sin(angle)
```

Где:

- `center_x = 300` — координата центра по оси X;
- `center_y = 300` — координата центра по оси Y;
- `R = 200` — радиус окружности;
- `angle` — текущий угол положения точки.

Для изменения положения точки угол увеличивается
или уменьшается на заданное значение скорости.

Положительная скорость обеспечивает движение
по часовой стрелке, отрицательная — против часовой.

Обновление изображения осуществляется
с помощью метода `after()` библиотеки tkinter.

## Тестирование

Для проверки корректности математической модели
используется стандартная библиотека unittest.

Запуск тестов:

```bash
python -m unittest discover -s tests -v
```

Тесты проверяют:

1. Начальное положение точки.
2. Соблюдение радиуса окружности.
3. Обновление угла движения.
4. Работу паузы.
5. Изменение направления.
6. Ограничения скорости.

## Пример использования

1. Пользователь запускает программу.
2. Открывается окно с окружностью.
3. Красная точка начинает движение по часовой стрелке.
4. При нажатии стрелки вправо скорость увеличивается.
5. При нажатии стрелки влево скорость уменьшается.
6. При нажатии R направление движения изменяется.
7. При нажатии пробела анимация останавливается.
8. Повторное нажатие пробела возобновляет движение.

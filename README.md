## Описание проекта

Программа предназначена для визуализации движения точки
по окружности с использованием библиотеки tkinter.

Проект разрабатывается на языке Python в рамках
лабораторной работы №1.

## Функциональные возможности

Планируется реализовать:

- Графическое окно размером 600×600 пикселей.
- Отображение окружности радиусом 200 пикселей.
- Анимацию движения точки по окружности.
- Изменение скорости движения точки.
- Изменение направления движения точки.

## Требования к системе

- Python 3.9 или выше.
- Библиотека tkinter.
- macOS, Windows или Linux с графическим интерфейсом.

## Установка и запуск

После завершения разработки проект можно будет запустить
следующим образом:

1. Клонировать репозиторий.
2. Перейти в папку проекта.
3. Создать виртуальное окружение.
4. Активировать виртуальное окружение.
5. Запустить программу командой:

```bash
python3 main.py
```

## Структура проекта

Структура будет дополняться по мере разработки.

## Пример использования

После запуска программы откроется окно с окружностью,
вдоль которой будет двигаться точка.

Пользователь сможет изменять скорость и направление движения.
